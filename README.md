## عن المنصة
 منصة تعليمية باللغة العربية تساعدك على تعلّم أساسيات JavaScript خطوة بخطوة. يجمع كل درس بين الشرح المبسّط والتطبيق المباشر، فتكتب الكود وتجرّبه داخل الصفحة نفسها دون الحاجة إلى تثبيت أي برنامج.

تتضمن المنصة :

- دروسًا مرتّبة تبدأ من الأساسيات وتتدرّج في المستوى
- محررًا برمجيًا داخل صفحات الدروس لتجربة الكود مباشرة
- أمثلة واختبارات تساعد المتعلّم على تثبيت ما يدرسه

## المساهمة
للمساهمة في تطوير الدروس أو الموقع، افتح [مستودع المشروع](https://github.com/nv8v/winter) وقدّم اقتراحك أو طلب التغيير.
