## عن المنصة

تقدّم المنصة دروسًا باللغة العربية في أساسيات JavaScript، مع محرر برمجي داخل صفحات الدروس وأمثلة واختبارات تساعد المتعلّم على تطبيق ما يدرسه.

## تشغيل المشروع محليًا

يتطلب المشروع [Deno](https://deno.com/).

```sh
deno task start
```

ثم افتح `http://localhost:8000`.

## البناء والنشر

```sh
deno task build
deno task export
```

ينشئ الأمر `export` نسخة ثابتة من صفحات الموقع داخل مجلد `dist`. يتم نشر هذه النسخة تلقائيًا إلى GitHub Pages عند الدفع إلى فرع `main`.

لتفعيل النشر، افتح إعدادات المستودع ثم **Settings → Pages**، واختر **GitHub Actions** كمصدر للنشر.

## المساهمة

للمساهمة في تطوير الدروس أو الموقع، افتح [مستودع المشروع](https://github.com/nv8v/winter) وقدّم اقتراحك أو طلب التغيير.
